# Profile: light

For small, low-risk projects: scripts, prototypes, personal tools. The core
applies in full.

- Non-trivial changes: state the intended change in a sentence or two before
  making it.
- Run the project's checks that cover the change, if any exist, before
  reporting it done.
- Read your own diff before reporting it done.
- Independent review is optional; recommend it when a change is risky.

This profile grants no permission to commit, push or deploy and never
overrides local instructions or the user. A risky task escalates to the
`standard` (`.harness/profiles/standard.md`) or `strict`
(`.harness/profiles/strict.md`) requirements for that task (see the core).
